=== CAUSE RACINE DU BLOCAGE ===
Deux manques distincts, pas un probleme d'environnement :
1. internal/tunnel est une bibliotheque de framing seule ; il n'existe AUCUN
   device TUN Linux ni AUCUN binding de stream libp2p dans le daemon.
2. internal/peering est instancie mais la table n'est ni alimentee par le
   reseau ni consommee par un routeur : c'est un objet inerte.
Donc un "cablage dans main.go" ne peut pas etre constate : le code a cabler
n'existe pas encore. Le test 2 noeuds + ping VIP->VIP est infaisable en l'etat
et n'a pas ete lance (le lancer produirait un faux negatif sans valeur).
